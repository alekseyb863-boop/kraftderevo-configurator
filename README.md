# Конфигуратор Kraftderevo (kraftderevo.ru)

**Онлайн-версия:** https://alekseyb863-boop.github.io/kraftderevo-configurator/

Параметрический конфигуратор мебельных ножек и подстолий (12 артикулов): ползунки, чертёж в стиле IKEA, выгрузка PNG/PDF/STL.
Геометрия считается в браузере (replicad + OpenCascade WASM) в Web Worker, сервер не нужен.
Сайт публикуется на GitHub Pages автоматически при каждом push в ветку `main` (`.github/workflows/deploy.yml`).

# Конфигуратор ножек и подстолий (Kraftderevo), v2

Веб-интерфейс, в котором любой из 12 артикулов собирается ползунками и сразу
показывается в виде чертежа в стиле IKEA (белый фон, чёрные линии, скрытые линии
убраны, размеры рядом с геометрией). 3D-превью нет, только чертёж.

Артикулы: Н031, Н005, Н050, Н112, Н028, Н030-2, Н043, Н038, Н098, 0090, 0011.

## Запуск

```bash
npm i
npm run dev        # режим разработки (Vite), http://localhost:5173
npm run build      # сборка в dist/
npm run preview    # просмотр собранной версии
```

Нужен **Node.js 26 (LTS «Lithium», 26.13.0 и новее)**: версия записана в `.nvmrc`
и в `engines` файла `package.json` (оба проекта, `configurator_v2/` и `replicad/`).
Установка: `nvm install` (читает `.nvmrc`) или `fnm use`, либо архив с https://nodejs.org/dist/v26.13.0/.
Node 20 снят с поддержки (30.04.2026), Node 24 — предыдущая LTS. Проверка: `node -v`.

Первая отрисовка занимает около секунды (загрузка WASM
OpenCascade, ~23 МБ, ~7 МБ в gzip), дальше пересчёт 15–80 мс.

## Как пользоваться

1. Выберите артикул (плитки вверху).
2. Двигайте ползунки или вводите числа. Значения за пределами диапазона
   поджимаются, невозможные сочетания (например, профиль шире ножки)
   исправляются с сообщением на русском, а не падением.
3. Выберите профиль (40×20, 50×25, 40×40, 60×30, 80×40; у Н098 — квадратные
   20…50) или полосу (60×6, 80×6, 80×8) и введите цвет.
4. Кнопки «PNG» (высокое разрешение, ×2,5, белый фон) и «PDF» скачивают чертёж, «STL» — 3D-модель. SVG на странице только для просмотра (кнопки скачивания нет), STEP не выгружается.

Модель всегда одно цельное тело без швов, с острыми внешними углами; габариты
точно равны заданным.

## Тесты

```bash
npm run test       # Playwright e2e: все 12 артикулов, по одному ползунку,
                   # проверка SVG и отсутствия наложений текста на линии;
                   # скриншоты в screens/<артикул>.png и screens/overview.png
npm run sweep      # геометрический прогон по сетке параметров (валидность
                   # тела, габариты, наложения; node, без браузера)
```

Для e2e нужен Chrome (`/usr/bin/google-chrome`) и `npm run build`.

## Структура

- `src/main.js`, `src/style.css`, `index.html` — интерфейс.
- `src/worker/cad.worker.js` — Web Worker с replicad и OpenCascade (WASM);
  запросы «последний побеждает», с задержкой (debounce).
- `src/png.js` — PNG: SVG → canvas ×2,5 → blob (при нехватке памяти масштаб снижается).
- `src/pdf.js` — PDF (jsPDF + svg2pdf). Текст в SVG/PDF/PNG — контуры (opentype.js,
  DejaVu Sans), поэтому шрифты не нужны.
- `src/shared/` — **копия** общего кода из `../replicad/` (модели, отрисовка).
  Источник правды — `replicad/`; обновить копию: `npm run sync`.
- `scripts/sync-shared.mjs` — синхронизация.

## Как добавить артикул

В `replicad/<артикул>/model.js` экспортируется `spec` (controls, normalize, parts,
dims, textLines, expectBBox, view, layout), затем артикул добавляется в
`replicad/registry.js`, после чего `npm run sync`. Тот же `spec` использует
`node build.js` в `replicad/` для эталонных PNG/STL.

## Ограничения

- У Н043 верхние пластины выступают за размер 555 (как в эталонной модели),
  поэтому габарит по ширине больше (~610 мм).
- Размер пластин Н030-2 / Н043 в тексте и размерах чертежа не показан.
- Направление трапеции ограничено: у Н005 и Н112 ширина верха ≤ ширины низа,
  у Н050 и Н043 ширина низа ≤ ширины верха.
- Протестировано только в headless Chrome.
